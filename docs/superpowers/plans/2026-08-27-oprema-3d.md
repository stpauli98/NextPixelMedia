# 3D oprema na stranici usluga — plan implementacije

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pet panela usluga na `/usluge` dobija 3D model opreme koja tu uslugu radi, rotiran skrolom.

**Architecture:** Jedno `<Canvas>` koje zauzima samo gornju polovinu viewporta, pa se model i tekst panela ne mogu preklopiti. `PinPanel` upisuje napredak skrola u mutabilni modul van Reacta; renderer ga čita u svojoj petlji, pa se React ne renderuje na svaku sličicu.

**Tech Stack:** three, @react-three/fiber, @react-three/drei, GSAP ScrollTrigger (postojeći), @gltf-transform/cli (razvojna).

**Spec:** [`docs/superpowers/specs/2026-08-27-oprema-3d-design.md`](../specs/2026-08-27-oprema-3d-design.md)

## Global Constraints

- Jezik sajta: BS/SR. Bez `[lang]` segmenta.
- Boje isključivo iz `@theme` tokena: `#0B1018` `#1E3A5F` `#C6A96B` `#F8F6F0` `#F5F5F3` `#8A919B`. Bez hardkodovanog hex-a u komponentama.
- Šampanj najviše ~10% površine; nikad kao pozadina sekcije. **Na svijetlim površinama akcenat je navy** — šampanj na cream je 2.09:1 i pada.
- **Svaka `vw` mjera treba `max-md:` pratioca**, prelom 768px. Grana je trenutno na nuli nesparenih — ne smije se pokvariti.
- Tekst ne živi u JSX-u; sav sadržaj iz `src/content/`.
- **Ništa se ne izmišlja.** Nema izmišljenih brojki, citata, logotipa ni ljudi.
- Svaka GSAP animacija ide kroz `useGsap`.
- `'use client'` samo gdje komponenta stvarno treba hook, stanje ili handler.
- Model bez potpune licence i atribucije **ne smije proći produkcijski build**.
- GLB nakon obrade: **≤ 800 KB**, teksture najviše 1024×1024, Draco kompresija.

## Struktura fajlova

| Fajl | Odgovornost |
|---|---|
| `src/content/modeli.ts` | Podaci o modelima: koji panel, autor, licenca, izvor |
| `src/lib/oprema.ts` | Mutabilno stanje van Reacta: koji model je aktivan i koliki mu je napredak |
| `src/components/oprema/Platno.tsx` | `<Canvas>` u gornjoj polovini ekrana, montira se jednom |
| `src/components/oprema/Model.tsx` | Učitava i renderuje jedan GLB, čita rotaciju iz `oprema.ts` |
| `src/components/oprema/Zasluge.tsx` | Vidljiva linija sa atribucijom autora |
| `public/modeli/*.glb` | Obrađeni modeli |
| `scripts/check-placeholders.mjs` | Četvrti sentinel: model bez licence obara build |
| `src/components/usluge/PinPanel.tsx` | Prijavljuje napredak skrola |
| `src/app/usluge/page.tsx` | Montira platno i zasluge |

**Redoslijed zadataka je namjeran:** zadaci 1–4 ne zavise od modela. Modeli traže **ručno preuzimanje** sa Sketchfaba (traži prijavu, agent to ne može), pa taj korak dolazi kasno i ne blokira ostalo.

- [ ] **Step 7: Proširi `scripts/check-placeholders.mjs`**

Dodaj `modeli` u ulazni objekat i novu provjeru uz postojeće tri:

```js
const NEPOTPUN_MODEL =
  '- modeli.ts sadrži model bez autora, licence ili izvora — atribucija je pravna obaveza, dopuni prije objave.'

function modeliNepotpuni(sadrzajModeli) {
  // Svaki unos mora imati neprazan autor, neprazna licenca i izvor koji
  // je stvarni URL. Prazan string prolazi TypeScript ali ne prolazi zakon.
  const unosi = sadrzajModeli.match(/\{[^}]*\}/g) || []
  return unosi.some((u) => {
    const autor = u.match(/autor:\s*'([^']*)'/)
    const licenca = u.match(/licenca:\s*'([^']*)'/)
    const izvor = u.match(/izvor:\s*\n?\s*'([^']*)'/)
    return (
      !autor?.[1]?.trim() ||
      !licenca?.[1]?.trim() ||
      !izvor?.[1]?.startsWith('https://')
    )
  })
}
```


```ts
/**
 * Stanje 3D opreme, namjerno VAN Reacta.
 *
 * Rotacija se računa na svakoj sličici. Da ova vrijednost ide kroz
 * useState, stranica bi se renderovala šezdeset puta u sekundi.
 * Renderer čita ovaj objekat u svojoj petlji; React saznaje samo
 * kad se promijeni KOJI je model aktivan, a to je rijetko.
 */
type Stanje = { aktivan: string | null; napredak: number }

const stanje: Stanje = { aktivan: null, napredak: 0 }

export function ulazi(id: string): void {
  stanje.aktivan = id
  stanje.napredak = 0
}

export function izlazi(id: string): void {
  // Paneli se preklapaju pri skrolu: onaj koji izlazi može javiti izlazak
  // nakon što je sljedeći već javio ulazak. Bez ove provjere bi obrisao
  // tuđi aktivni model.
  if (stanje.aktivan === id) {
    stanje.aktivan = null
    stanje.napredak = 0
  }
}

export function napreduj(id: string, v: number): void {
  if (stanje.aktivan !== id) return
  stanje.napredak = v
}

export function citaj(): Readonly<Stanje> {
  return stanje
}
```

```tsx
'use client'

import { useRef } from 'react'
import { useFrame } from '@react-three/fiber'
import { useGLTF } from '@react-three/drei'
import type { Group } from 'three'
import { citaj } from '@/lib/oprema'

const PUN_KRUG = Math.PI * 2

// Ugao pod kojim model stoji kad je pokret isključen. Bira se tako da se
// oprema prepozna — ne frontalno, nego blago zaokrenuto.
const MIRAN_UGAO = PUN_KRUG * 0.12

function pokretIskljucen(): boolean {
  if (typeof window === 'undefined') return false
  return window.matchMedia('(prefers-reduced-motion: reduce)').matches
}

export function Model({ id }: { id: string }) {
  const grupa = useRef<Group>(null)
  const { scene } = useGLTF(`/modeli/${id}.glb`)
  const mirno = useRef(pokretIskljucen())

  useFrame(() => {
    if (!grupa.current) return

    // Spec §4.4: pri reduce model se VIDI ali se ne vrti. Funkcija se ne
    // uklanja — samo prestaje rotacija. Postavlja se jednom i ostaje.
    if (mirno.current) {
      grupa.current.rotation.y = MIRAN_UGAO
      return
    }

    const { aktivan, napredak } = citaj()
    if (aktivan !== id) return
    grupa.current.rotation.y = napredak * PUN_KRUG
  })

  return (
    <group ref={grupa}>
      <primitive object={scene} />
    </group>
  )
}
```

- [ ] **Step 3: Napiši `src/components/oprema/Platno.tsx`**

Platno zauzima **samo gornju polovinu** viewporta. To je cijelo rješenje problema preklapanja: paneli drže sav sadržaj u donjoj trećini, pa se model i tekst geometrijski ne mogu sresti — bez ijednog `z-index` proračuna.

```tsx
'use client'

import { Suspense, useEffect, useState } from 'react'
import { Canvas } from '@react-three/fiber'
import { citaj } from '@/lib/oprema'
import { Model } from './Model'

export function Platno() {
  const [aktivan, postaviAktivan] = useState<string | null>(null)
  const [radi, postaviRadi] = useState(true)

  // Stanje se mijenja van Reacta; ovdje ga anketiramo samo da bismo znali
  // KOJI model montirati. Rotacija ide direktno kroz useFrame, ne ovuda.
  useEffect(() => {
    const otkucaj = setInterval(() => {
      const sada = citaj().aktivan
      postaviAktivan((prosli) => (prosli === sada ? prosli : sada))
    }, 120)
    return () => clearInterval(otkucaj)
  }, [])

  if (!radi) return null

  return (
    <div
      aria-hidden="true"
      className="pointer-events-none fixed inset-x-0 top-0 z-[7] h-1/2"
    >
      <Canvas
        dpr={[1, 1.5]}
        camera={{ position: [0, 0, 4], fov: 45 }}
        gl={{ alpha: true, antialias: true }}
        onCreated={({ gl }) => {
          // Izgubljen kontekst (telefon u pozadini, reset GPU-a) ne smije
          // srušiti stranicu niti ostaviti mrtvo platno preko sadržaja.
          gl.domElement.addEventListener('webglcontextlost', (e) => {
            e.preventDefault()
            postaviRadi(false)
          })
        }}
      >
        {/* Svjetla su izričita, bez drei <Stage> i bez `environment` preseta.
            Ti preseti dovlače HDR mapu sa vanjskog CDN-a — dodatni megabajti
            i vanjska zavisnost na sajtu koji je inače samodovoljan. */}
        <ambientLight intensity={0.6} />
        <directionalLight position={[3, 4, 5]} intensity={1.6} />
        <directionalLight position={[-4, 1, -3]} intensity={0.5} />

        <Suspense fallback={null}>{aktivan && <Model id={aktivan} />}</Suspense>
      </Canvas>
    </div>
  )
}
```

> **Bez spinnera.** `fallback={null}` je namjerno: posjetilac ne zna da tu nešto treba da bude, pa vrtuljak samo skreće pažnju na odsustvo.

```tsx
if (model) {
  // Dva režima, jer se panel različito kreće. Na desktopu je pinovan i
  // troši 100% visine ekrana; na mobilnom je obična sekcija koja prolazi
  // kroz viewport. Isti raspon bi na mobilnom dao pogrešan napredak.
  mm.add(
    {
      desktop: '(min-width: 768px)',
      mobilni: '(max-width: 767px)',
    },
    (kontekst) => {
      const jeDesktop = kontekst.conditions?.desktop === true

      const st = ScrollTrigger.create({
        trigger: korijen,
        start: jeDesktop ? 'top top' : 'top bottom',
        end: jeDesktop ? '+=100%' : 'bottom top',
        onEnter: () => ulazi(model.id),
        onEnterBack: () => ulazi(model.id),
        onLeave: () => izlazi(model.id),
        onLeaveBack: () => izlazi(model.id),
        onUpdate: (self) => napreduj(model.id, self.progress),
      })

      return () => st.kill()
    },
  )
}
```
